Migration Familiale

Application personnelle de migration de données entre deux comptes Google.

Présentation

Migration Familiale est un programme privé pour Windows, développé en Python et utilisant l'API YouTube Data API v3.

Il permet de sauvegarder les abonnements, les playlists et les vidéos aimées d'un compte source, puis de les recréer dans un compte de destination, dans les limites techniques de l'API.

Utilisation

Le programme est exclusivement destiné à un usage familial et personnel, avec l'autorisation des titulaires des comptes concernés.

Il n'est pas commercialisé, ne génère aucun revenu et n'est pas accessible au public.

Fonctionnement et sécurité

L'application utilise l'authentification officielle Google OAuth 2.0. Les données de migration et les informations d'authentification sont enregistrées localement sur l'ordinateur.

Aucune donnée personnelle des comptes concernés n'est publiée sur ce site.
